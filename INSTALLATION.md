# Installation Guide

## Quick Install

### Prerequisites
- Firefox 109 or newer
- Active Chess.com account (to see boards)

### Steps

1. Download the Extension
   - Clone or download this repository

2. Get Piece Images
   - Download the Alpha theme pieces from GiorgioMegrelli's chess.com-boards-and-pieces repository on GitHub
   - Navigate to pieces/alpha folder in that repository
   - Download all 12 PNG files
   - Place them in pieces/alpha/ folder in this extension

   Required files:
   - wp.png, wn.png, wb.png, wr.png, wq.png, wk.png
   - bp.png, bn.png, bb.png, br.png, bq.png, bk.png

3. Verify File Structure
